## 3. デザインの原則

1. **内容が主役**：飾りで目を引かない。表、グラフ、出典、見出しと段落で、情報の構造をそのまま見せる（DS-01、DS-09）。
2. **白書と辞典の紙面**：白い背景、濃紺のヘッダーの帯、緑の差し色、1pxの罫線、十分な余白。強調は太字と緑の印だけで行う。仕組みは、本サイトで作る図と装置の絵で見せる（7章）。
3. **少ない値を、何度も使う**：文字の大きさは7段階、余白は8段階、色は、基本の色18、状態の色5、グラフの色9に限る。同じ役割には、どのページでも同じ値を使う。
4. **数字を読ませる**：数値は等幅の数字（桁がそろう数字）で右に揃え、単位、期、出典を必ず添える（DS-02）。
5. **誰でも使える**：JIS X 8341-3のレベルAA（DS-03）。色だけで区別しない。キーボードだけで操作できる。
6. **動かさない**：動きは、開閉など操作の結果だけにする。端末の「視差効果を減らす」の設定では、動きを止める。

## 5. 文字と文字組み

### 5.1 書体
端末の文字を使う（1.3）。和文はゴシック体だけとし、明朝体は使わない。Macではヒラギノ角ゴシック、WindowsではBIZ UDPゴシック（Windowsに入っている読みやすさを重視した書体）を先に使う。Webフォントは使わない。

```css
--font-family-base: "Hiragino Sans", "Hiragino Kaku Gothic ProN", "BIZ UDPGothic", system-ui,
  -apple-system, "Yu Gothic UI", "Yu Gothic", "Noto Sans JP", Meiryo, sans-serif;
--font-family-mono: ui-monospace, "SFMono-Regular", Menlo, Consolas, "Noto Sans Mono", monospace;
```

* 斜体は使わない（和文に斜体の字形がない）。
* 太さは、標準（400）と太字（700）の2つだけとする。

### 5.2 文字の段階
大きさは`rem`（端末の文字の大きさの設定に従う単位）で指定する。1remは16pxを基準とする（UI-08）。

* 本文の1行は、全角で約35〜45字に収める。本文の最大幅は`--content-max-width: 40rem`（17pxの文字で約37字）とする。
* 段落の間は`--space-5`（1.5rem）空ける。字下げはしない。
* 見出しの上の余白は、下の余白の2倍以上にして、見出しが後ろの段落に属して見えるようにする（`##`は上`--space-7`、下`--space-4`）。

### 5.3 文字組みの規則
* **見出しと導入の折り返し**：見出しと導入の文字（`--text-lead`）は、単語や文節の途中で折り返さない。`word-break: auto-phrase`（対応する閲覧ソフトで文節の切れ目で折り返す）と`text-wrap: balance`（行の長さをそろえる）を付ける。対応しない閲覧ソフトでは、普通に折り返す。
* **約物の詰め**：見出し、ボタン、表の見出しには`font-feature-settings: "palt"`（括弧や句読点の空きを詰める）を付ける。本文には付けない（読みやすさを優先する）。
* **数字**：表、主要な数値、グラフの目盛りには`font-variant-numeric: tabular-nums`（桁がそろう数字）を付ける。表の数値は右に揃える。
* **単位**：表では、単位を列の見出しに書き（「売上高（億円）」）、各セルには数字だけを書く。文章では、数字と単位を続けて書く（「8,325.5億円」）。
* **長い語**：URLや英語の長い名前は、枠からはみ出す場合だけ折り返す（`overflow-wrap: anywhere`）。
* **強調**：太字（700）だけを使う。下線はリンクだけに使う。文字の色を変えて強調しない。
* **文の調子**：記事の本文（`content/`のMarkdown）は、である調とする（CLAUDE.md 5.1）。画面の案内の文（404のページ、状態の表示、注記・未反映などの表示、ボタン、入力の誤り、仮のページの注記）は、です・ます調とする（2026年10月6日、運営者）。

## 7. 罫線、角、図と記号

| 変数 | 値 | 用途 |
| :--- | :--- | :--- |
| `--border-width` | 1px | 区切り、表、部品の枠 |
| `--border-width-accent` | 4px | 要点の印（左の太い線） |
| `--border-width-focus` | 3px | フォーカスの枠 |
| `--focus-offset` | 2px | フォーカスの枠と要素の間 |
| `--radius-control` | 2px | ボタン、入力欄、タグ |
| `--radius-card` | 10px | 入口のカード（トップ、半導体を学ぶの一覧）、工程の流れの図の段階と帯、noteの案内、主要な数値の右の「サプライチェーン上の位置」、前後のページの案内（8.21）、理解度チェックの枠、用語の定義の枠、まとめの枠、「さらに深く」、「この解説の企業」 |

| `--radius-pill` | 999px | タグ、絞り込みのチップ（8.19）、ヘッダー・トップ・検索のページの検索欄（丸い形） |
| `--radius-none` | 0 | それ以外（表、注記、部品の枠、広告の枠（8.23）） |

* グラデーション、半透明のぼかしは使わない（運用ルール書10.3.3）。影は、カードを浮かせる弱い影`--shadow-card`（`0 1px 2px` と `0 4px 12px` の、濃紺の6%・5%）の1種類だけとし、トップの帯からはみ出す4つの入口だけに使う。それ以外の重なりは、罫線と背景の色で示す。
* トップの帯の地（9.1）には、半導体の世界から取った2つの線を敷く。回路の直交の格子（32pxごと、`--color-brand-grid`の1pxの線）と、帯の右に中心を置いたウェーハの同心円（4本、`--color-brand-ring`の1pxの線。上端にノッチを示す`--color-brand-accent`の短い線）。どちらも読み上げの対象にせず（`aria-hidden`）、文字の後ろで文字の読みやすさを下げない濃さに保つ。ほかのページには敷かない。
* アイコンと記号は、使ってよい（1.4。飾りの目的だけのものも含む）。例：外部リンクの印、開閉の印、並べ替えの印、警告の印、トップページの入口の絵、「半導体を学ぶ」の分野の絵、工程の一覧のリンクの印（工程の解説：本、売上高などを比べる：棒グラフ）。次を守る。
  * SVGで作る。線の太さは1.5px（`--icon-stroke`）を基本とし、大きさは文の中の記号が1.25rem（`--icon-size`）、トップの入口の絵が2.75rem（`--icon-entry`。4rem（`--icon-entry-tile`）の下地の中）、分野の絵が2.25rem（`--icon-field`。3.5remの下地の中。分野のページの頭では3.25remの絵を5remの下地に）。
  * 色は、線を`--color-primary`（「半導体の物理」の絵は`--color-brand`）、下地を`--color-surface-sunken`とし、絵の中の小さな印（点や小さな面）にだけ琥珀（4.4）を使う。マウスを重ねたときは、下地を`--color-primary-tint`にする（分野のカードでは面と下地を入れ替える）。
  * 文字のラベルと必ず組にする。アイコンだけで意味を伝えない。アイコンは、読み上げの対象にしない（`aria-hidden`）。
  * 同じ意味には同じアイコンを使う。
  * 絵文字は使わない。
* 仕組みを説明する図（工程の流れ、装置の断面、構造の模式図）は、本サイトでSVGで作り、工程・用語・学習のページで積極的に使う。線と面は4章の色、文字は本文と同じ書体と大きさの段階を使い、図の中の文字は読み上げ用の説明（`role="img"`と`aria-label`）にも書く。図の下に「図：（何の図か）。模式図、本サイトで作成」の説明を付ける。寸法や比率を正確に表す図でない場合は「模式図」と書く。写真は使わない（使う場合は、許諾と出典の書き方を本書に足してから）。
* トップページの入口の絵は、行き先を表す線の図（半導体を学ぶ：開いた本とチップ、工程を学ぶ：ウェーハから箱を経てチップへ進む流れ、ニュースを読む：記事の紙面、企業を比べる：建物と棒グラフ）とする。
* 「半導体を学ぶ」の分野の絵は、分野の中身を表す線の図とする（1. 半導体の基礎：結晶の格子、2. 半導体材料とウェーハ：ノッチのあるウェーハ、3. デバイス設計・回路：論理ゲート、4. 製造プロセスと装置：膜の断面、5. 検査と信頼性：チップに当てる針、6. パワー半導体：交流から直流への波形、7. センサー・計測：画素の並びと入る光、8. 通信・信号処理：アンテナと電波、9. 工場と業界：のこぎり屋根の工場、A. 固体物理学：バンドとすき間、B. 半導体デバイス物理：pn接合のバンドの曲がり、C. 光物性：バンドに入る光、D. 結晶・材料の物理：立方体の格子）。分野を足すときは、同じ考え方で絵を足し、本書のこの一覧に加える。

* 部品は`src/components/AdSlot.astro`の1つだけとする。広告のコードは、この部品の中だけに書き、ページのテンプレートに直接書かない。部品は「広告」の表示を必ず出し、表示を消す引数を持たない（LG-02）。
* 広告を出さない設定のとき（AD-301）、本番では、部品は何も出力しない（枠も、空の要素も出さない）。CSSで隠す方法は使わない。

**見た目**

| 部分 | 値 |
| :--- | :--- |
| 外側の枠 | 背景`--color-surface-sunken`、`--border-width`の`--color-border`の枠、角`--radius-none`、影なし。内側の余白`--space-3` |
| 「広告」の表示 | 枠の左上に、`--text-small`、`--color-text-muted`、太さ400で「広告」とだけ書く。「スポンサーリンク」「おすすめ」「PR」など、ほかの言葉にしない（「PR」は求人の枠と参考書の欄に使う。運用ルール書5.3、5.5） |
| 表示と広告の領域の間 | `--space-2` |
| 広告の領域 | 下の表の高さを先に確保し、読み込みでページがずれないようにする（UI-05）。広告が入るまでは空のままにし、文字や印を出さない |
| 枠の上下の余白 | `--space-7` |

* 外側の枠には、本文の部品（カード、注記、要点の枠、入口）と同じ面・角・線・影を使わない。本文とひと目で区別できるようにするためである（DS-05）。

**大きさ**

| 位置 | 幅 | 広告の領域の高さ | 変数 |
| :--- | :--- | ---: | :--- |
| 本文の列（スマートフォン） | 本文の列の幅 | 100px | `--ad-height-compact` |
| 本文の列（タブレット、PC） | 本文の列の幅（最大`--content-max-width`） | 250px | `--ad-height` |
| PCの右の列 | 右の列の幅（16rem） | 250px | `--ad-height` |

* 広告の大きさは画像の画素に合わせて決まるため、この2つの変数だけはpxで持つ。
* スマートフォンの枠全体（表示、余白、枠の線を含む）は約160pxとなり、幅360px・高さ640pxの画面の3分の1（約213px）以下に収まる（AD-405、運用ルール書5.2）。
* 広告の大きさは、AdSenseのレスポンシブ広告ユニットに、上の高さをCSSで指定する方法で合わせる（AdSenseが認めるコードの変更の範囲）。

**置き方の決まり**

* 枠は画面に張り付かせない（`position: sticky`と`fixed`を使わない。AD-406）。
* PCの右の列では、右の列を上の部分（目次と、ニュースの個別では「この解説の企業」（8.22））と下の部分（広告の枠）に分ける。目次が張り付く範囲は上の部分の中に限り（8.4）、広告の枠は右の列の下端に置く。目次と広告の枠を重ねない。
* 「PCの右の列」の枠は、PCより狭い幅では広告を要求しない（広告のコードを動かさない）。読み込んだ後に画面の幅が狭くなったときも、広告を隠さない（AdSenseのポリシーで、広告を隠すことは禁止されている）。
* 枠の近くに、矢印、アイコン、絵、「クリック」などの操作を促す言葉、本サイトのボタンやカードに似せた飾りを置かない。枠の中には、「広告」の表示のほかに、本サイトの文字やリンクを置かない。
* グラフ、表、マップと枠の間には、見出しか段落を挟む（運用ルール書5.2）。
* Cookieの利用の確認（8.15）を表示している間は、広告を読み込まない。閲覧者が選んだ後に読み込む。

**読み上げと操作**

* 枠は`aside`の要素とし、`aria-label="広告"`を付ける。枠の中で、キーボードの選択の順番を変えない。

**プレビューの見本の枠**

* プレビューでは、AdSenseのコードを出さず、同じ大きさの枠に「広告」の表示と、広告の領域に「広告の枠の見本（プレビューだけに表示）」の文字（`--text-small`、`--color-text-muted`）を出す。位置と大きさを、本番に出す前に確かめるためである。本番には、見本を出さない。

## 9. ページの型

ここでは、各ページの並びと、幅ごとの変化を定める。内容の順は要件定義書3.2〜3.4に従う。

### 9.1 トップページ（`/`）
1. **帯（ヒーロー）**：ヘッダーと続けて、`--color-brand`の帯を最初の画面に置く。地に回路の格子とウェーハの同心円の線を敷く（7章）。帯の中は1列（最大40rem）とし、上から、大見出し（`--text-display`、`--color-on-brand`。強調する語「つなげて」だけ`--color-brand-accent`）、説明の一文（`--text-lead`、`--color-on-brand-lead`、最大34rem）、大きな検索欄（8.6）を置く。帯の上下の余白は`--space-8`（スマートフォンは`--space-6`）、下には入口がはみ出す分（56px、スマートフォンは48px）を足す。掲載企業・工程・ページの数は表示しない（1.4）。
2. **4つの入口**（要件定義書3.3）：帯の下端から56px（スマートフォンは48px）はみ出して重ねる。PCは4列、タブレットとスマートフォンは2列×2行、間は`--space-3`。各入口は、白い面、`--color-border`の枠、`--radius-card`、`--shadow-card`、内側の余白`--space-5`（スマートフォンは`--space-4`）のカードとし、全体を1つのリンクにする。上から、入口の絵（7章）、見出し（`--text-lead`の太字。右端に`--color-primary`の「→」）、一文の説明（`--text-small`の補助の色）。マウスを重ねたときは、枠を`--color-primary`、絵の下地を`--color-primary-tint`にする。入口の見出しと説明は、「半導体を学ぶ：中学理科から、基礎編9分野を順に」「工程を学ぶ：ウェーハからチップまでの流れ」「ニュースを読む：どの工程・どの企業の話かを解説」「企業を比べる：売上高・利益率・給与を並べて」とする。
3. **半導体ができるまで**：中見出しの右に、右端まで伸びる1pxの罫線と「工程の一覧へ」のリンク（中見出しの共通の形。5・6も同じ）。その下に一文の説明（`--text-dense`の補助の色）と、工程の流れの図（9.4の工程の一覧と同じ部品）を置く。
4. **工程の流れの図**：設計・材料・前工程・後工程の4つの段階を左から並べ、段階の間に、点と矢印でつないだ線（`--color-border-strong`）を置く。各段階は、白い面、`--color-border`の枠、`--radius-card`の箱とし、頭（段階の面の色。段階の色の小さな四角と段階の名前（`--text-dense`の太字、段階の文字の色）、右に「ウェーハに回路を作る・9工程」のような補足（`--text-caption`の補助の色））の下に、工程を1行ずつ並べる（工程の名前と、右に関わる掲載企業の数「10社」。行全体が工程ページへのリンク。マウスを重ねたときは面を`--color-primary-tint`）。列の幅の比は、設計1、材料1、前工程1.35、後工程1.1。下に、工場設備の帯（白い面、分類の名前、一文の説明、企業の数。分類の企業の一覧へのリンク）と、できあがる半導体の帯（`--color-stage-devices-tint`の面。主な種類と代表の企業）を2列で並べる。タブレットでは段階を2列×2行、スマートフォンでは1列にし、段階の間の線を消す。
5. **新着のニュース解説**：上に`--color-text`の1pxの罫線を引き、各件を`--color-border`の罫線で区切る（カードにしない）。各件は、左（4.5rem）に日付（「10月16日」。`--text-small`の補助の色、等幅の数字）、右に見出し（`--text-body`の太字、`--color-text`。下線はマウスを重ねたときだけ）と、3日以内のものに「新着」の印、その下に段階のタグと企業のタグ（8.11）。5件。
6. **近く開かれるイベント**（FR-206）：5と同じ罫線の並び。左（4.5rem）に暦の形の日付（`--radius-cal`の枠。上の帯は`--color-brand`の面に白い文字で月（ビルドの年と違うときは「2027年2月」の形）、その下に開始日（1.5remの太字）と終わりの日（`--text-caption`の補助の色））、右にイベントの名前（`--text-dense`の太字。公式ページへの外部リンク）と、会場・主催者（`--text-small`の補助の色）。読み上げ用に、開催日を文字でも書く。5件まで（1.5）。下に出典。
7. **運営者のnoteの案内**：6の下に、`--color-primary-tint`の面、`--radius-card`。左に「n」の丸の印。
* PCでは、5を左の列（約6割）、6と7を右の列（約4割）に並べる。PCより狭い幅では、5の下に6と7を置く。3・5の間は`--space-8`（スマートフォンは`--space-7`）。
* 最初の画面（幅360px、高さ約640px）に、1の大見出し・説明・検索欄が収まることを確かめる（UI-16）。

### 9.2 企業ページ（`/companies/{slug}/`、詳細掲載）
* PC：企業の頭と主要な数値の帯（8.8）は、外枠の幅いっぱいに置く。その下を、本文の列と右の列（目次）にする。スマートフォン：1列、目次は開閉式。
* 並び（要件定義書3.4）：パンくずリスト→企業の頭と主要な数値（8.8）→目次→事業概要・工程上の位置づけ→業績（グラフと表）→同じ工程の企業と比べる→IR重要ポイント→働く環境→ニュース→資料→出典・関連。本文の中見出し（`##`）の上には、`--color-border`の罫線を引く。
* 業績：売上高と営業利益を、同じグラフの棒を2本並べて示す（売上高`--chart-cat-1`、営業利益`--chart-cat-3`。凡例を上に置き、最新の期の棒の上に数値を書く）。グラフの直後に、同じ数値と営業利益率の表を「表で見る」の開閉で置く。グラフの見出しは「売上高と営業利益の推移」。営業利益の値がない会社は、売上高だけの1系列のグラフ（`--chart-single`、凡例なし。見出しは「売上高の推移」）にする。
* セグメントのグラフでは、半導体関連のセグメントを`--chart-highlight`、それ以外を`--chart-other`で示し、凡例と数値のラベルを付ける。
* 同じ工程の企業と比べる：その会社の主な工程（`processes`の最初の工程）の掲載企業のうち、詳しいページのある企業を、売上高の大きい順に1行ずつ並べる。各行は、企業名（その会社自身は太字でリンクにしない）、売上高の横棒（最大の企業を100%とする。幅8rem、スマートフォンは4rem、`--color-primary`）、売上高（等幅の数字、右揃え）。上を`--color-border`の罫線で区切る。下に「エッチングの掲載企業11社のうち、詳しいページのある2社。」と、企業一覧へのリンクを書く。

### 9.3 企業一覧（`/companies/`）

* 初めの並び順は、売上高の大きい順。企業名・売上高・比率・利益率・給与の見出しを押すと並べ替える（もう一度押すと逆順。企業名は証券コード順）。並べ替えの印は、並べ替えている列だけ`--color-primary`の「▼」「▲」、ほかは補助の色の「↕」。
* 企業名の列は、横にスクロールしても左に固定する。行にマウスを重ねたときは、面をごく薄い灰色にする。
* 表の下に、定義と範囲の注記（`--color-surface-sunken`の面。営業利益率は全社の連結の数値で、半導体事業だけの数値ではないこと。平均年間給与は提出会社の従業員の数値で、持株会社では事業会社の水準を表さないこと。会計基準の違いで、営業利益の定義が異なる場合があること）と出典を置く。注記の文言は、企業ページの「働く環境」の注記（FR-803）と同じ部品を使う。
* カードの格子にしない。

### 9.4 工程の一覧（`/processes/`）と工程ページ（`/processes/{slug}/`）
* 工程の一覧：ページの頭（8.3。大見出し、一文の説明、更新日）の下に、工程の流れの図（9.1の4と同じ部品。工程の行は、同じページの下の工程の説明へ移動する）と、工場設備・できあがる半導体の帯を置く。

### 9.7 検索の結果（`/search/`）
* ページの頭（8.3）に、大きな検索欄（8.6）を置き、その下に種類の絞り込み（8.19。すべて・企業・工程・用語・テーマ・ニュース・イベント。件数つき。結果のない種類は出さない）。

### 9.8 広告の枠の差し込み位置（運用ルール書5.1）

## 10. グラフ

### 10.1 形の選び方
| 内容 | 形 |
| :--- | :--- |
| 売上高・利益の推移 | 縦の棒（期ごと）。1系列なら`--chart-single` |
| セグメント別の売上の推移 | 積み上げの縦の棒。半導体関連を下に置き、`--chart-highlight`と`--chart-other`で示す |
| 地域別の売上（1期） | 横の棒（大きい順）。円グラフは使わない |
| 従業員数・平均年間給与の推移 | 折れ線（2本以上なら凡例と線の種類を変える） |
| 1つの数字 | グラフにせず、数値の表示（8.8）にする |

* 2つの縦軸を持つグラフは作らない。単位の違う数値は、グラフを分ける。

### 10.2 形の細部
* 棒の幅は、棒と棒の間の1.5倍。積み上げの部分の間は、背景の色の2pxの隙間。
* 折れ線は2px、点は8px以上。
* 目盛りの線は`--chart-grid`の1px、横の線だけ。軸の線は`--chart-axis`。
* 金額の縦軸は0から始める（DS-02）。例外は部品の指定と注記が要る。
* 数値のラベルは、最新の期と、注目する値にだけ付ける（すべての棒に付けない）。
* 並べた棒（売上高と営業利益など、期ごとに系列の棒を横に並べる形）：棒の間は2pxの隙間、棒の幅は最大32px。最新の期の数値は、細い棒の上に横に並べると重なるため、系列の名前を添えて（「売上高 24,435.3」「営業利益 6,249.4」）、棒の組の上へ1行ずつ、グラフの右端にそろえて書く（積み上げのラベルと同じ置き方）。吹き出しと読み上げには、期・系列の名前・数値・前期比を入れる。
* 文字は本文の書体、`--text-small`以上、文字の色は`--color-text-muted`（系列の色を文字に使わない）。
* 増減は「＋」「−」と矢印を添える。色だけで示さない。

### 10.3 グラフの部品に必ず渡すもの
タイトル、単位、期間、出典と確認日、系列の名前、表で見るための同じ数値（DS-02、CLAUDE.md 9章）。

### 10.4 操作
* ビルドのときにSVGとして作る（要件定義書FR-301）。年次／半期、指標の切り替えは、作っておいたグラフを切り替える。
* 数値は、棒や点を選ぶ（タップ、クリック、キーボード）と、その近くに出す。マウスを重ねたときだけに出る情報にしない。どの数値も「表で見る」で読める。
