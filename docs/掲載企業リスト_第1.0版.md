## 1. 本書の位置づけ

運用ルール書4.4.2の「選定の作業表」にあたる。掲載企業（100社程度）と、MVPの詳細掲載の20社を、1つの表にまとめる。企業マスタ（`data/companies/{slug}.yaml`）を作るときの元になる。

* 決めるのは運営者である。本書はClaudeが作った下書きであり、掲載の最終の判断は運営者が行う（運用ルール書4.4.2）。
* 運営者が挙げた企業と、Claudeが補った企業を区別せずに、同じ基準で並べている。
* 本書で確定した内容は、企業マスタの`selection`（掲載の理由）に写す。詳細掲載の企業は、判断の根拠の資料（`selection.source`）を付ける。Coming Soonの企業は、本書を根拠とし、`selection.source`は書かない（データ定義書4.1.2。運営者の判断、2026年10月4日）。

## 2. 読み方

### 2.1 区分（運用ルール書4.4.1）

| 区分 | 企業マスタの`type` | 基準 | 掲載の根拠（`selection.basis`） |
| :--- | :--- | :--- | :--- |
| 国内上場企業 | `domestic_listed` | 半導体関連の売上が全社の売上の30%以上（目安） | `revenue_ratio` |
| 総合メーカー | `conglomerate` | 半導体関連の比率が30%未満でも、世界シェアの上位（上位3社程度）に入る半導体関連の製品を持つ | `global_share` |
| 外資系日本法人 | `foreign_subsidiary` | 国内に主要な生産拠点を持つ | `domestic_fab` |

### 2.2 分類（データ定義書4.3）

7つの分類（設計、前工程、後工程、材料、装置、デバイス、検査）から、該当するものをすべて付ける。一覧の「分類」の1つ目を主な分類とし、一覧を主な分類ごとに分けて並べた。

### 2.3 列の意味と、確認の状態

| 列 | 内容 | 確認の状態 |
| :--- | :--- | :--- |
| 企業名、証券コード、EDINETコード | EDINETコードリストと照合した。証券コードは4桁で書いた（EDINETの5桁の末尾の0を除く） | 照合済み。ただし、上場している間の値であり、変更は決算の時期に確かめる |
| 区分、分類 | Claudeが、事業の内容から付けた | 暫定。売上比率と世界シェアは、公開資料での確認が未実施 |
| 売上規模 | 全社の売上の概算。大は1兆円以上、中は1,000億円以上1兆円未満、小は1,000億円未満 | 暫定。Claudeの推定で、決算書での確認は未実施 |
| 検索の多さ | 高、中、低。就職活動での知名度と、検索で探されやすさの推定 | 暫定。検索の候補表示やキーワードの調査ツールでの確認は未実施 |
| 世界シェア上位の製品 | 主な製品。「—」は、該当が分からない、または確認していないもの | 暫定。公開資料での確認は未実施。確認できるまで、企業ページには書かない |
| slug | 企業ページのURLに使う識別名。EDINETの英字名から作った | 暫定。公開したら変えられないため、企業マスタを作る前に確定する |
