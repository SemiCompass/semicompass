## メモリは、0と1を覚えておく部品

前の分野では、MOSFETがスイッチとして働き、組み合わせると計算ができることを学んだ。計算には、計算する部品だけでなく、計算に使う情報や結果を覚えておく部品も欠かせない。この、情報を0と1の形で覚えておく半導体の部品を「メモリ」と呼ぶ。

メモリは、一つの0か1を覚える小さな単位（セル）を、縦と横に非常に多く並べて作る。どのセルを読み書きするかは、縦と横の配線を選んで決める。

メモリには、電源を切ると内容が消えるものと、電源を切っても内容が残るものがある。前者を「揮発性」、後者を「不揮発性」と呼ぶ。このページでは、それぞれの代表であるDRAMとNAND型フラッシュメモリを見ていく。

## DRAM：ためた電気で覚える

DRAMのセルは、トランジスタ一つと、電気をためるコンデンサー一つでできている。コンデンサーに電気がたまっている状態を1、たまっていない状態を0とする。

トランジスタは、コンデンサーへの出入り口の扉である。書き込むときは扉を開けて、コンデンサーに電気を入れたり、抜いたりする。読み出すときも扉を開けて、電気がたまっているかどうかを調べる。

部品が二つだけなので、一つのセルを小さく作れる。そのため、同じ面積に多くのセルを並べられ、たくさんの情報を覚えられる。また、読み書きが速い。

## DRAMは、書き直し続ける必要がある

コンデンサーにためた電気は、時間がたつと少しずつ漏れていく。放っておくと、1だったセルが0と区別できなくなる。

そこで、DRAMでは、一定の時間ごとに全部のセルを読み出し、同じ内容を書き直している。この動作を「リフレッシュ」と呼ぶ。DRAMの「D」は、この動的（ダイナミック）な書き直しを指している。

電源を切ると、リフレッシュができなくなり、内容は消える。DRAMは揮発性のメモリである。速く読み書きできるので、コンピューターが計算の途中で使う作業用のメモリ（主記憶）に使われる。

## NAND型フラッシュメモリ：電子を閉じ込めて覚える

NAND型フラッシュメモリのセルは、MOSFETの形に、電子をためておく層を一つ加えたものである。ゲートとチャネルの間に、周りを絶縁膜で囲んだ層を置く。

書き込むときは、ゲートに高い電圧をかけて、チャネルの電子を絶縁膜の向こうのこの層へ押し込む。いったん入った電子は、周りの絶縁膜に囲まれているので、電源を切っても逃げにくい。そのため、内容が残る。NAND型フラッシュメモリは不揮発性のメモリである。

読み出すときは、トランジスタが入になりやすいかどうかを調べる。層に電子がたまっていると、そのマイナスの電気がゲートの働きを打ち消し、チャネルができにくくなる。この違いで、0か1かを見分ける。

## NAND型の特徴と、立体に積む工夫

NAND型は、セルを鎖のように縦につないで並べる。セルの間の配線を減らせるので、同じ面積に多くのセルを詰め込める。一方で、消すときはセル一つずつではなく、まとまった単位でまとめて消す。

書き込みと消去をくり返すと、電子が通り抜ける絶縁膜が少しずつ傷んでいく。そのため、書き換えられる回数には限りがある。製品では、書き込む場所を散らすなどの工夫で、特定のセルだけが傷まないようにしている。

一つのセルに、電子の量を何段階かに分けて覚えさせ、0と1を複数個ぶん記録する方法もある。また、平面にセルを並べるだけでなく、セルを縦に何層も積み上げる作り方が広がっている。積み上げたセルをつなぐため、非常に深く細い穴を垂直に掘るエッチングや、その穴の内側に均一な膜を付ける成膜が欠かせない。

## 使い分けと、メモリの階層

コンピューターは、性質の違うメモリを組み合わせて使う。

計算する部品のすぐそばには、トランジスタだけで作る速いメモリ（SRAM）を置く。SRAMは速いが、セルが大きく、多くは載せられない。その外側に、容量が大きく速いDRAMを置き、作業中の情報を持つ。さらにその外側に、電源を切っても内容が残るNAND型フラッシュメモリを置き、写真や文書などを長く保存する。

速いメモリほど少なく、容量の大きいメモリほど遅い。この段々の組み合わせを「メモリの階層」と呼ぶ。計算する部品とメモリの間で情報をやり取りする速さが、全体の性能を左右することも多い。DRAMのチップを積み重ね、計算する部品のすぐ横に置いて多くの配線でつなぐHBMは、この課題に向けた作り方である。

## このページのまとめ

メモリは、0と1を覚えておく部品である。DRAMは、トランジスタとコンデンサーで作り、ためた電気で覚える。電気が漏れるのでリフレッシュが必要で、電源を切ると内容は消える。NAND型フラッシュメモリは、絶縁膜に囲まれた層に電子を閉じ込めて覚え、電源を切っても内容が残る。コンピューターは、速さと容量の違うメモリを階層にして組み合わせる。

## 理解度チェック

### 問1
DRAMのセルが情報を覚える仕組みとして、正しいものはどれか。

1. コンデンサーに電気がたまっているかどうかで、0と1を覚える
2. 磁石の向きで、0と1を覚える
3. 光の色で、0と1を覚える
4. ダイオードの向きを入れ替えて、0と1を覚える

答え：1
解説：DRAMのセルは、トランジスタ一つとコンデンサー一つでできていて、コンデンサーにためた電気の有無で0と1を覚える。

### 問2
DRAMで「リフレッシュ」が必要な理由として、正しいものはどれか。

1. 読み出すたびに、トランジスタが壊れるから
2. コンデンサーにためた電気が時間とともに漏れるため、一定の時間ごとに書き直す必要があるから
3. 電源を切ったときに、内容を残すため
4. セルを縦に積み上げるため

答え：2
解説：コンデンサーの電気は少しずつ漏れていくので、DRAMは一定の時間ごとに全部のセルを読み出して書き直す。電源を切ると書き直しができず、内容は消える。

### 問3
NAND型フラッシュメモリが、電源を切っても内容を残せる理由として、正しいものはどれか。

1. 内容を常に別のDRAMに写しているから
2. 小さな電池を内蔵しているから
3. 周りを絶縁膜で囲んだ層に電子を閉じ込めていて、電子が逃げにくいから
4. コンデンサーを大きく作っているから

答え：3
解説：NAND型では、ゲートとチャネルの間にある、絶縁膜で囲まれた層に電子を押し込んで覚える。電子は絶縁膜に囲まれているので、電源を切っても逃げにくい。
