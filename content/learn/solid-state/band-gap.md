## 式

$$E_g = E_c - E_v$$

$E_c$ は伝導帯の底のエネルギー、$E_v$ は価電子帯の頂上のエネルギーである。その差 $E_g$ が、バンドギャップである。単位には電子ボルト（eV）を使う。1 eVは、電子1個が1 Vの電位差を移るときに得るエネルギーである。

光で電子を持ち上げるときは、光の粒（光子）1個のエネルギーと比べる。

$$h\nu = \frac{hc}{\lambda} \geq E_g$$

$h$ はプランク定数、$\nu$ は光の振動数、$c$ は光の速さ、$\lambda$ は波長である。この不等式が成り立つ光だけが、価電子帯の電子を伝導帯へ持ち上げられる。

## 式のどこを見るか

式そのものは引き算だけである。読みどころは、$E_g$ を何と比べるかにある。比べる相手は、熱、光、電界の3つである。

一つ目は熱との比べである。熱が電子に与えるエネルギーの目安は $kT$ で、$k$ はボルツマン定数、$T$ は絶対温度である。$E_g$ が $kT$ より何十倍も大きいと、熱で伝導帯に上がる電子はごくわずかになる。どれだけ減るかは $E_g/kT$ が指数の中に入る形で決まり、その形は「真性キャリア濃度と温度」のページで読む。帯どうしが重なる金属にはこのすき間がなく、すき間が非常に大きい物質は電気をほとんど通さない絶縁体になる。半導体は、その間にある。

二つ目は光との比べである。不等式を波長について解くと $\lambda \leq hc/E_g$ になる。$hc$ を eV と nm の単位で表すと約1240になるので、吸収できる最も長い波長は、およそ1240を $E_g$ の値で割った nm になる。$E_g$ が大きい材料ほど、短い波長の光しか吸収しない。それより長い波長の光は、材料を通り抜ける。光を出す部品では、出せる光の色の目安にもなる。

三つ目は電界との比べである。$E_g$ が大きい材料では、強い電界で加速された電子が、ほかの電子を価電子帯からたたき出しにくい。そのため、壊れずに耐えられる電界（絶縁破壊電界）が大きい傾向がある。同じ電圧に耐える層を薄く作れるので、パワー半導体で$E_g$ の大きい材料が使われる。

## 数値例

室温付近のバンドギャップは、シリコン（Si）が1.12 eV、ガリウムヒ素（GaAs）が1.43 eV、炭化ケイ素（4H-SiC）が3.26 eV、窒化ガリウム（GaN）が3.39 eVである[S1]。

300 Kの $kT$ は、ボルツマン定数（$8.617\times10^{-5}$ eV/K）[S2]から約0.026 eVになる。シリコンの $E_g$ はその約43倍、炭化ケイ素は約126倍である（本サイトで計算）。

プランク定数と光の速さ[S2]から $hc$ は約1,240 eV·nmになる。吸収できる最も長い波長は、シリコンで約1,107 nm（近赤外）、ガリウムヒ素で約867 nm、炭化ケイ素で約380 nm、窒化ガリウムで約366 nm（紫外）である（本サイトで計算）。

絶縁破壊電界は、シリコンの $3.0\times10^{5}$ V/cmに対し、炭化ケイ素が $2.8\times10^{6}$ V/cm、窒化ガリウムが $3.3\times10^{6}$ V/cmで、およそ10倍の違いがある[S1]。

## 理解度チェック

### 問1
バンドギャップが大きい材料ほど、吸収できる光はどうなるか。

1. より長い波長の光まで吸収できる
2. より短い波長の光しか吸収できない
3. 波長によらず、すべての光を吸収する
4. 光をまったく吸収しなくなる

答え：2
解説：吸収できる最も長い波長は、およそ1240を Eg の eV の値で割った nm である。Eg が大きいほど、この波長は短くなる。

### 問2
熱で伝導帯に上がる電子の数を読むとき、バンドギャップと比べる量はどれか。

1. 光の速さ c
2. 絶縁破壊電界
3. 熱のエネルギーの目安 kT
4. 原子の数

答え：3
解説：熱が電子に与えるエネルギーの目安は kT である。Eg が kT より何十倍も大きいと、熱で越える電子はごくわずかになる。
